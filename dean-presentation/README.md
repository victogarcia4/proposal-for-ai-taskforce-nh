# North Harris AI Use Norms dean presentation

Open `index.html` in a modern browser. The presentation is self-contained and does not require a development server.

The presentation uses a fixed 16:9 slide canvas that fits the available browser height. Each slide advances individually rather than becoming a scrollable page.

The 17-slide presentation includes the current six-table question bank, with four questions shown for each table.

For a single-file copy that bundles the HTML, CSS, JavaScript, screenshots, and portrait, open `North_Harris_Dean_Presentation.html`. Rebuild it after editing the source files by running `node build-standalone.mjs` from this folder.

Controls:

- Right and left arrows, Space, Page Up, and Page Down move through slides.
- The on-screen controls provide full-screen mode and printing.
- Slides 3 and 4 explain the OTS resource evidence gap and the justification for a local inquiry.
- Slides 9 through 14 display the current six-table, 24-question bank, four questions per table.
- Slide 15 contains an interactive simulated walkthrough using fictional public demo data.

The complete word-for-word presenter script is in [SPEAKER_NOTES.md](SPEAKER_NOTES.md). It is deliberately separate from the visual presentation.

## Included assets

- Creator portrait provided in the project: Dr. Victor Garcia M.

## Visual basis

The deck uses the public Lone Star College Brand & Logo Styleguide as a visual reference: LSC blue (`#003768`) is dominant, red (`#b30838`) is used sparingly, and type stacks prioritize Futura and Trajan where available. It does not create or alter an institutional logo.

## Content boundary

The presentation describes the app as a consultation tool. It does not claim that live collection, institutional approval, or production governance activation has occurred.

The OTS resource comparison reflects the pages reviewed October 7, 2026. Confirm tool status with OTS. The proposed inquiry distinguishes opinions, knowledge, and self-reported use. Voluntary consultation responses cannot establish campus-wide prevalence or substitute for a validated knowledge assessment.
