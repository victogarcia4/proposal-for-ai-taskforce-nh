Compare Generative AI Tools and Check Appropriate Data Levels

The below table shows Generative AI tools currently available from the Office of Technology Services, including the level of confidential Lone Star College data for which these tools are approved.

Many other AI tools are available to the public, including tools that are free to use. However, per Lone Star College guidelines, you should not enter data classified as Confidential or Restricted into publicly-available Generative AI tools.

As always, if you're considering using Generative AI tools for Lone Star College work, you must follow the College's initial guidelines for use.
